# Задание: tools/book.py

Один скрипт на Python 3 с подкомандами. Зависимость — только pyyaml.

## scaffold

Читает блок кода в `PLAN.md` и создаёт папки и файлы по CONVENTIONS.md.

- Глава: строка `^(\d+)\. (.+)$`. Строки сразу под ней с отступом
  до первой подглавы — описание главы.
- Подглава: `^\s+(\d+)\.(\d+) (.+)$`. Следующие строки с отступом,
  не являющиеся подглавой, — тезис.
- Строки `ЧАСТЬ ...` и текст под ними до первой главы — пропускать
  (или класть в `book/parts.yaml`).
- Метки `[П1]`, `[П3–П5]`, `[П3, П4]` вынести из заголовка в `techniques`.
  Ссылки `(→ гл. N)` оставить в тезисе, но не в имени файла.
- Имя папки: `NN-slug`, где slug — транслит части названия после
  двоеточия (если есть), иначе первых 3–4 слов. Имя файла: `MM-slug`
  из первых 1–3 слов подзаголовка.
- Создаёт шапки со `status: план`. НЕ перезаписывает существующие файлы.
- Если подглава из PLAN.md пропала, а файл есть — предупредить, не удалять.

## status

Таблица: id, заголовок, статус, round. Внизу — счётчики по статусам.

## next

Первая по порядку подглава со статусом не `принято` и не `нужен человек`.

## check [id]

Порядок файлов: по номеру главы, внутри — index.md, затем по номеру
подглавы. Проверяются файлы со статусом не `план`. Текст: без шапки
и без блоков кода (```...```) и инлайн-кода (`...`).

Ошибки:
1. Термин (term и все forms, с границами слов) встречается в файле,
   который идёт раньше `introduced_in`.
2. Аббревиатура (kind: abbr): в каждом абзаце первое упоминание должно
   сразу (через пробел) продолжаться «(». Вывод: файл, строка, абзац.
3. Термин из `introduces` шапки отсутствует в реестре или у него
   другой `introduced_in`.
4. Термин из `defined_via` введён позже самого термина.
5. Ссылка на несуществующий термин в `defined_via`.

Предупреждения:
6. Неизвестная аббревиатура: латинское слово из 2+ заглавных букв/цифр
   (`\b[A-Z][A-Z0-9]{1,}\b`, плюс варианты с дефисом и /), которого нет
   в реестре. Список исключений — `terms/allowlist.txt`.

Код выхода 1 при ошибках. Вывод на русском, коротко, по строке на проблему.

## Тест

Создать временную копию с 2–3 подглавами, где специально нарушены
правила 1, 2, 4, 6, и убедиться, что check их находит.

## Уточнения реализации (2026-10-30)

Решения, которых не было в задании, приняты при написании скрипта:

- **Заголовки** (`# …`) не проверяются правилом 2: расшифровка в заголовке
  ломает навигацию. Правило 1 на них действует. Первое упоминание
  в абзаце под заголовком должно быть с расшифровкой.
- **Абзац** — блок между пустыми строками. Пункт списка, строка таблицы
  и заголовок — отдельные абзацы.
- **Скобки расшифровки.** Аббревиатуры внутри «(…)» сразу после другой
  аббревиатуры не считаются первым упоминанием: «QUIC (Quick UDP
  Internet Connections — …)» не требует расшифровки UDP внутри.
- **Суффикс между аббревиатурой и скобкой допустим:** «HTTP/3 (…»,
  «TLS 1.3 (…», «TCP-соединение (…».
- **Правило 1** — по одному сообщению на термин в файле (первое место).
  Русские термины ищутся без учёта регистра, аббревиатуры — с учётом.
- **Правило 4:** термин и его `defined_via` могут быть введены в одной
  подглаве (порядок внутри файла скрипт не знает).
- **Предупреждение 6** дополнительно ловит кириллические аббревиатуры
  из 2–4 букв («ОС») и формы вида `IPv4`. Не ловит римские числа
  («ЧАСТЬ IV») и метки приёмов («П5»). Составные «TCP/IP», «SYN-ACK»
  считаются известными, если известны все части.
- **Также ошибки:** термин записан в реестре дважды; `introduced_in`
  указывает на несуществующую главу или подглаву.
- **scaffold** ищет файлы по `id` в шапке, а не по имени: если заголовок
  в PLAN.md поменялся, старый файл не дублируется. Папку главы находит
  по номеру. `book/parts.yaml` пересоздаётся при каждом запуске.
- Указатели А, Б, В из PLAN.md получают id «А», «Б», «В» и папки 90–92.
- `--root ПУТЬ` — запуск на другой копии репозитория.
- Тест: `python3 tools/test_book.py` — временная копия с ошибками правил
  1–6.
