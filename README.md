# net-from-zero — «Сети с нуля»

Техническая книга со схемами о том, как данные передаются от одного
устройства к другому: от сигнала в кабеле до HTTP/3 (HyperText Transfer
Protocol version 3 — протокол передачи гипертекста, версия 3), VPN
(Virtual Private Network — виртуальная частная сеть) и обхода блокировок.

Читатель — человек, который умеет пользоваться компьютером, но в сетях
не знает ничего. Цель — не сделать из него сетевого инженера,
а дать прочную модель, в которую укладывается любая новая технология.

## Как устроен репозиторий

| Файл / папка | Что там |
|---|---|
| `CLAUDE.md` | Точка входа для агента ИИ |
| `RULES.md` | Правила книги: цель, читатель, стиль, шаблон главы |
| `PLAN.md` | Оглавление |
| `DECISIONS.md` | Журнал решений и их причины |
| `WORKFLOW.md` | Цикл написания и проверки подглав |
| `CONVENTIONS.md` | Имена файлов, шапки, реестр терминов |
| `book/` | Текст: папка на главу, файл на подглаву |
| `terms/terms.yaml` | Реестр терминов |
| `prompts/` | Промты ролей: автор, читатель, фактчекер, редактор, правщик |
| `tools/book.py` | Каркас, статусы, проверка терминов |

## Как задать вопрос по тексту

Откройте issue по шаблону «Непонятно», укажите номер подглавы
и напишите своими словами, что не понятно. Агент найдёт, какого звена
объяснения не хватило, и перепишет текст.

## Быстрый старт на сервере

```
git clone <адрес репозитория>
cd net-from-zero
pip install -r requirements.txt
python3 tools/book.py status
```
