# Соглашения

## Файлы книги

```
book/
├── 00-kak-chitat-etu-knigu/
│   └── index.md
├── 11-tcp/
│   ├── index.md            вступление главы, в конце — тезисы и словарь
│   ├── 01-chto-proishodit-s-paketami.md
│   ├── 04-rukopozhatie.md
│   └── ...
└── ...
```

- Папка главы: номер с ведущим нулём (`00`–`43`) + короткое слово
  латиницей, по возможности термин из названия главы (`11-tcp`, `16-dns`).
- Файл подглавы: номер подглавы с ведущим нулём + 1–3 слова транслитом.
- Указатели и глоссарий: `book/90-ukazatel-simptomy/`, `book/91-ukazatel-priemy/`,
  `book/92-glossariy/`.
- Русский заголовок — только внутри файла.

## Шапка файла подглавы

```yaml
---
id: "11.4"
title: "Рукопожатие"
thesis: "SYN → SYN-ACK → ACK, согласование MSS"
techniques: [П2, П6]          # приёмы из RULES.md
status: план                  # план | черновик | проверка | нужен человек | принято
round: 0                      # номер круга проверки (максимум 3)
introduces: [SYN, SYN-ACK, MSS, рукопожатие]   # термины, вводимые здесь
goals:                        # что читатель должен суметь объяснить после подглавы
  - "Зачем нужны три сообщения, а не одно"
  - "Что каждая сторона записывает в память после рукопожатия"
---
```

`goals` пишет автор-агент. Агенту-читателю шапка НЕ передаётся:
он видит только текст.

## Реестр терминов `terms/terms.yaml`

```yaml
- term: TCP
  kind: abbr                  # abbr — аббревиатура, term — обычный термин
  expansion: "Transmission Control Protocol — протокол управления передачей"
  introduced_in: "11"         # id подглавы или главы, где введён
  defined_via: [порт, пакет, соединение]   # через какие термины объяснён
  definition: "Протокол, который ..."
  forms: []                   # другие написания: «TCP-соединение» и т.п.

- term: порт
  kind: term
  introduced_in: "10.1"
  defined_via: [пакет, заголовок]
  definition: "16-битное число в заголовке ..."
  forms: [порта, порту, портом, порты, портов, портам, портами, портах]
```

- Для русских терминов в `forms` перечисляются падежные формы,
  иначе скрипт их не найдёт.
- Термин нельзя использовать в тексте раньше `introduced_in`.
- Каждый термин из `defined_via` должен быть введён раньше самого термина.

## Статусы

| Статус | Значение |
|---|---|
| план | Только шапка из PLAN.md |
| черновик | Автор-агент написал текст |
| проверка | Идёт цикл проверки |
| нужен человек | 3 круга не сошлись — читает автор проекта |
| принято | Прошёл все проверки и/или одобрен автором |

## Коммиты

Сообщение коммита начинается с id подглавы: `11.4: черновик`,
`11.4: правка по issue #12`, `PLAN: глава 33 объединена с 34`.
